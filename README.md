## 🐍 Apartado 2: Fundamentos de Python (6 puntos)

> **Objetivo:** Resolver tres problemas básicos para afianzar la lógica de programación en Python. Los scripts se encuentran en la carpeta `apartado_2`.

### Problema 1: Procesamiento de una lista de enteros

Función que recibe una lista de enteros y devuelve otra aplicando estas reglas:

1. Eliminar números negativos.

2. Eliminar valores repetidos.

3. Ordenar de menor a mayor.
   *Ejemplo:* Entrada `[4, -1, 2, 4, 3, -5, 2]` ➔ Salida `[2, 3, 4]`.

### Problema 2: Frecuencia de palabras en un texto

Función que cuenta cuántas veces aparecen ciertas palabras (pasadas por lista) dentro de un fichero de texto.

* **Requisitos:**

  1. Eliminar signos de puntuación y convertir a minúsculas.

  2. Usar un diccionario (clave: palabra, valor: frecuencia).

  3. Devolver los resultados ordenados alfabéticamente por la palabra.

### Problema 3: Trabajo con conjuntos

Función que calcula operaciones matemáticas entre dos listas de enteros. **(Uso obligatorio de `sets` para los cálculos)**:

1. **Intersección:** Elementos comunes en ambos.

2. **Unión:** Todos los elementos sin duplicados.

3. **Diferencia simétrica:** Elementos exclusivos que están en uno u otro conjunto, pero no en ambos.
